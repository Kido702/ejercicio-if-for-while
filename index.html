1. Condicional IF / ELSE IF / ELSE Condición

if (nota >= 90) { "Excelente" } else if (nota >= 60) { "Aprobado" } else { "Reprobado" }

2. Bucle FOR Ciclo Definido

Genera la tabla de multiplicar completa del 1 al 10 para el número ingresado.

3. Bucle WHILE Ciclo Condicional

Cuenta regresiva desde el número elegido hasta 0 simulando el lanzamiento de un cohete.

while (contador >= 0) { console.log(contador); contador--; }
